# Créditos de assets de terceros

- **DejaVu Sans** (`fonts/DejaVuSans.ttf`, `fonts/DejaVuSans-Bold.ttf`)
  Usada para incrustar texto Unicode en el PDF de exportación
  (`lib/domain/export/pdf_builder_red.dart`): la fuente base Helvetica del
  paquete `pdf` no tiene glifos para tildes/ñ ni para símbolos usados en la
  memoria de cálculo.
  Licencia: [Bitstream Vera Fonts License](https://dejavu-fonts.github.io/License.html)
  (permisiva, permite embeber y redistribuir). Mismo archivo, sin cambios,
  ya usado en `sistema-diseno-almacenes/assets/fonts/`.
