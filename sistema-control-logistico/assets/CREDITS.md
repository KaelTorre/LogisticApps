# Créditos de assets de terceros

- **DejaVu Sans** (`fonts/DejaVuSans.ttf`, `fonts/DejaVuSans-Bold.ttf`)
  Usada para incrustar texto Unicode en los PDF de exportación
  (`lib/domain/export/pdf_builder_informes.dart`): la fuente base Helvetica
  del paquete `pdf` no tiene glifos para tildes/ñ.
  Licencia: [Bitstream Vera Fonts License](https://dejavu-fonts.github.io/License.html)
  (permisiva, permite embeber y redistribuir). Mismo archivo, sin cambios,
  ya usado en `sistema-diseno-almacenes/assets/fonts/` y
  `sistema-red-distribucion/assets/fonts/`.
