# LogisticApps
Repositorio principal de apps desarrolladas dentro del curso de Logistica. Los diferentes softwares presentados buscan facilitar procesos logísticos presentes en las diferentes empresas.

## Proyectos

- [sistema-gestion-pedidos-sla/](./sistema-gestion-pedidos-sla/) — Unidad 2: gestión de pedidos con nivel de servicio (OMS + SLA Tracker), Flutter multiplataforma.
- [sistema-optimizacion-rutas/](./sistema-optimizacion-rutas/) — Unidad 3: optimización de rutas de vehículos (VRP) con OSRM, Flutter multiplataforma.
- [sistema-diseno-almacenes/](./sistema-diseno-almacenes/) — Unidad 4: diseño y dimensionamiento de almacenes (plano 2D, isométrico, ficha técnica), Flutter multiplataforma.
- [sistema-red-distribucion/](./sistema-red-distribucion/) — Unidad 5: optimización de red de distribución (ubicación de centros, heurísticas de ubicación discreta), Flutter multiplataforma.
- [sistema-control-logistico/](./sistema-control-logistico/) — Unidad 6: control logístico de lazo cerrado (reglas de patrón, clasificación de desviaciones, acciones correctoras), Flutter multiplataforma. En desarrollo.
